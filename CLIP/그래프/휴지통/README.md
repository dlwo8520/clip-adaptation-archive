# Legacy graph copies

**Category:** Graph evidence / Prompt and adapter baselines

**Repository path:** `CLIP/그래프/휴지통/`

## Purpose

Preserves older graph collections and their historical directory structure for evidence traceability.

## Evidence and status

Saved plots and tables survive here. A graph does not recover missing run settings or establish a newly completed experiment. Duplicate graph copies are not additional seeds.

## Recorded condition

- Related family: `CLIP-002`; see the experiment registry for source packages.
- Exact historical collection: `휴지통`.
- Evidence type: standalone saved graph/table collection.

Compare target and preservation axes together. Best-case figures are post-hoc selections, not unbiased averages. Original filenames are retained even where names are inconsistent; table contents and provenance determine interpretation.
