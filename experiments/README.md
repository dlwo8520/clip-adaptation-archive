# Experiment registry and evidence cards

**Category:** Experiment management

**Repository path:** `experiments/`

## Purpose

Assigns stable IDs to research families and connects methods to code, configs, analyses and result state.

## Evidence and status

The registry distinguishes reference code, completed records, incomplete runs and diagnostics. It is an index rather than an independent result source.
