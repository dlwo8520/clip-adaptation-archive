# Reconstructed research history

1. Base CoOp/visual adapter packages define target adaptation and preservation evaluation and preserve original zero-shot baselines.
2. Wrapper selection implementations add random/confidence/margin/prototype/negative-confidence variants. Entropy-only explicitly changes the uncertainty definition.
3. Text-drift selection adds a vocabulary perturbation score to the existing selection framework; reference-distillation packages extend the trainer with reference constraints and optional prompt anchoring.
4. Two-teacher, weight-consolidation and full-data LoRA-teacher packages preserve separate support scoring/resource choices. Their trainer imports and original method documents establish the extension relation.
5. The JS package documents a high-entropy anchor followed by JS quantile diagnostics, including fallback into neighboring bins. Its plotted results survive but full raw run metadata does not.

These are supported implementation dependencies, not invented calendar entries. Parallel branches are not assigned an exact order. Many files share a relocation mtime, so mtime is not a research date. Closure is supplied by the researcher; no reason for stopping is inferred.

Nonempty records, graph-only evidence, code-only methods and empty files are distinguished in the experiment catalogue. Negative observations and older code copies remain available. No “SOTA method” milestone is added.
