# Third-party source and attribution

Original upstream headers, author names, citation blocks and licenses found in the source trees are retained. Nested paper-facing READMEs describe their original authors' research, not a publication by the owner of this archive. The repository root README states the owner's exploratory status.

No new project-wide license is imposed over mixed-origin research code. Consult each upstream source's license/permissions before redistribution. A missing license is not a grant. CDS, RevisitingCIL, adapted CoOp/CLIP ideas and BeyondObjects are identified in source documents and Git provenance. Experimental adaptations must not be called official full reproductions. Paper PDFs, datasets and model weights are excluded; references remain in the original documents.
